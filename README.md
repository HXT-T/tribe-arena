# 族群竞技场

设计你的族群性格，让它们替你对战。

玩家不亲手操作对局，只设计族群：成员怎么觅食、逃命、围猎、回巢、看家，巢穴什么时候孵化、建什么设施。然后把族群放进竞技场，和其他族群在同一套规则下较量。

## 运行

直接用浏览器打开 `life0.html`，不需要安装任何东西。

- 页面顶部"设计你的族群"：编辑成员性格（最多 8 条规则）和巢穴决策（最多 5 条）。
- 上场观战：你的族群对三个预设族群，可以调速度、跟随单个成员、看每条规则的命中率。
- 测试强度：自动跑一批对局，给出两两对决矩阵。

## 世界规则

1. 体型就是能量：吃东西变大，活着慢慢变小。
2. 越大越慢，但看得越远。
3. 大吃小：大 15% 以上，碰到就吃掉；但越大越吃不下，体量 40 就撑满了。
4. 得分 = 族群拥有的全部体量：巢里储量 + 成员 + 设施。
5. 只能用巢里的储量孵化、建设施；敌人碰到你的巢会偷走储量，除非有自己人在家。
6. 设施也是体量：比它大的敌人能吃掉它。
7. 在自己领地里耗能减半。
