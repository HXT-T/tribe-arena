# 角色竞技游戏 · 总纲（v0.3，2026-11-07）

> 暂名未定。灵感来自 RMTC，规则、名称、美术全部原创。

## 初心

几千年来，游戏都是人类亲自下场博弈：围棋、象棋、扑克、电子竞技，比的都是人的临场判断。
这个游戏要做的是下一步：**人类不再亲自下场，而是创造智能，让智能替自己博弈。**
比的不再是手速和临场反应，而是你对这个游戏的理解有多深，以及你能不能把这种理解交给一个 bot。

这正是 AI 时代的处境：越来越多的事情不再由人亲手去做，而是由人创造、指挥、调教 AI 去做。会和 AI 协作、能把自己的意图准确交给 AI，正在成为每个人的基本能力。
这个游戏让普通人在一个简单、公平、好玩的舞台上，亲身体验"创造智能"这件事。

**乐趣就来自设计本身**，不来自操作，也不来自数值成长：

> 想出一个点子 → 交给 bot → 看它对战 → 发现它聪明或愚蠢的地方 → 改进 → 再战

一切设计都为这个循环服务：规则简单，点子才容易想；看得懂，才知道 bot 为什么输；公平，赢了才说明你的点子真的好。

## 一句话

**设计或养成你的自动化 bot，让它们替你对战。**

玩家从不亲手操作对局。玩家的全部本事都体现在 bot 身上：要么亲手设计它的性格，要么像训练宠物一样把它养成。对局开始后，一切由 bot 自己完成。

圆台推挤是第一个竞技场，用来承载这个本质；以后的模式和场地都是新的舞台，bot 不变。

## 两条路径：设计与养成

两条路径产出同一种东西：一份 bot 的**性格规则**（加上体型）。两种玩家可以在同一个天梯里对战。

| | 设计 | 养成 |
|---|---|---|
| 玩家做什么 | 直接写、改"条件 → 动作"规则 | 训练它：看回放时表扬或纠正某个行为、安排陪练对手、亲手示范一段操作让它模仿；以后还可以在生命世界里育种，从后代中挑出表现好的变种 |
| bot 怎么变 | 玩家改了哪条就变哪条 | 训练结果自动调整规则和权重，玩家随时可以打开看它"学会了什么" |
| 乐趣 | 造出来的成就感 | 看它一点点长大的陪伴感 |

**AI 助手贯穿两条路径**：玩家可以直接用中文说出想法（"开局躲在边上，等别人打完再冲"），助手把它翻译成规则或训练建议，并解释 bot 为什么输。助手只帮忙，最终的规则始终摆在玩家眼前，由玩家确认。

**养成的公平**：每个 bot 的训练次数有固定上限。比的是怎么训练，不是训练多久；投入时间更多不会更强。

## 原则

**目标是一个简洁优雅的核心玩法：容易理解，变化丰富。** 具体用什么形式实现，还在探索，不预设答案。
每加一条规则、一个参数，都要回答：没有它，游戏会少掉什么？答不出就不加。

### 已确定 / 待探索

| 已确定 | 待探索 |
|---|---|
| 初心与乐趣循环 | 核心玩法的具体形式 |
| 玩家设计或养成 bot，不亲手操作对局 | bot 的身体由哪些要素构成 |
| bot 是画面中会动的实体 | 性格的表达方式和词表 |
| 公平只来自 bot 本身，对局确定可复现 | 每局人数、计分方式 |
| 用自动对局验证玩法 | 扩展机制选哪些 |

下文的"圆台推挤"是**第一个候选**，用来做原型验证，不是定论。

**2026-11-07 决定：先做"能量生态"候选**（见附录），原型 `arena/life0.html`（Life-0）。首轮测试（每组 3 个种子 × 3000 刻）：
- 豆豆（快繁草食）在两两对决中全胜，獠（掠食者）只在对豆豆时拿到约 40%。
- 根本原因很可能是**能量金字塔**：能量每往上传一级就损失一部分，所以只要按"能量占比"计分，草食在结构上就占优。下一步要决定的是计分方式或捕食规则，而不是调参数。
- 已出现部分克制：秃克獠、墩克獠、墩克秃。

**同日调整：从"模拟生态"改为"族群竞技"**（生态只借规则，主角是玩家设计的族群）：
- 世界规则：体型就是能量；越大越慢、看得越远；大吃小；回巢存放，储量（加设施）就是得分；只能在巢里孵化和建造；设施也是体量，比它大的敌人能吃掉它；在自己领地里耗能减半。
- 设施：农田（附近长草）、墙（挡住较小的敌人）、哨塔（扩大警戒范围）、前哨（第二个存放点，扩展领地）。
- **玩家入口**：页面顶部的"设计你的族群"。成员性格最多 8 条"若 A 且 B → 动作"，巢穴决策最多 5 条"若 储量/成员/设施 条件 → 孵化/建造"，加上携带线和保留体量两个参数。可以从预设开始改，一键上场观战或批量测试。
- 首轮测试（预设之间）：农夫（经营）领先，象群克狼群，狼群克蜂群。蜂群不停孵化花掉储量，得分低；农田产量已从每刻 0.2 下调到 0.04，仍偏强。平衡留给后续用批量测试调整。

**平衡第一轮（2026-11-07）**：先加能量流水统计，再按原因改规则，不靠盲调。
- 发现：族群之间几乎没有交锋（3000 刻里吞噬和偷窃只有几十），胜负全靠经济；食物有全场总上限，巢穴附近被吃空后不再长，远处堆满却没人去，农田食物还挤占了野外食物的名额；只计储量时，孵化等于扣分。
- 改动：食物改为固定草点，被吃后原地定时再生，中央草点更密，形成争夺区；农田自带草点，不再挤占野外食物；得分改为族群拥有的全部体量（储量 + 成员 + 设施）；维持成本改为与体量成正比，体型和速度的取舍更陡；偷巢速度从每刻 1.5 降到 0.6；预设族群重写。
- 结果（新种子 6 个，均值 ± 标准误）：四方混战 狼 29±2 / 蜂 25±4 / 农 24±3 / 象 22±3，较均衡。两两对决中狼群对所有对手都赢（59–64%），其余三者之间接近五五开。
- 遗留问题：偷巢缺少反制手段；不含狼群的对局里仍然零交锋。

**看家规则（同日）**：新增"巢里有自己人时偷不走"，以及条件"我离巢最近"、动作"看家"。
- 有效：给蜂群加上"有敌入侵、离巢最近的回家看守"后，被偷从 66 降到 18。
- 但狼群反而更强（两两对决 69–70%）：看家的小个子被大狼吃掉。狼群真正的优势是**体型压制**（大吃小），不是偷巢。
- 试过"同伴合围"（几个同伴同时碰到敌人时按总体量算），没有可测量的效果，已撤回。
- 目前找到的最好反制打法"重象"（携带 34、保留 16、救援同伴、追猎）对狼群为 43%，仍未形成克制。
- 预设族群暂不加看家规则，留给玩家自己写。

**撑死机制（同日）**：吸收率随体型下降，体量 20 以下全额吸收，到 40 降为零（吃食物、吃敌人、偷巢都适用）。
- 调参用的种子上，狼群两两对决降到 51–54%；换 6 个新种子验证为 56–60%（之前 59–64%）。有改善，但调参种子上的效果有一部分是过拟合。
- 新种子四方混战：狼 25±1 / 蜂 28±3 / 农 24±1 / 象 22±3。

**可玩性第一轮（2026-11-08）**：
- 比赛 3000 刻结束，显示排名。
- 能量账本：每个族群的采食、吞噬、偷得、被吞、被偷、耗能、投资，并自动指出你的族群最大的短板。
- 挑战预设：一对一 6 个种子，按得分占比评金（≥55%）、银（≥50%）、铜（≥40%），浏览器记录最好成绩。
- 默认设计改为只有 4 条规则的简单起手族群，玩家在它上面构建策略。
- 频率依赖检验：场上狼群越多，每个狼群的平均得分并没有下降（1 狼 25%，3 狼 28%），与生产者与掠夺者模型的预测相反；蜂群在多方混战中较强（29–30%）。
- **重要发现：设计梯度很弱。** 4 条规则的起手族群对四个精心设计的预设得分 45–50%，说明设计好坏对结果影响偏小。这是"让玩家体会设计乐趣"的头号问题，需要先量化：随机设计、起手设计、精心设计之间的差距有多大。

**设计梯度量化（2026-11-08）**：强度 = 一对一对四个预设的平均成绩；搜索用种子 7000+，结论用新种子 8000+ 复核（每个设计 16 局）。
- 噪声：同一设计换一组种子，得分占比相差约 1–2 个百分点（标准误 1–2）。
- 随机设计（25 个，2–8 条随机规则）：得分占比中位数 28%，最高 41%。差在缺少"吃、回巢"这类基本规则。
- 起手设计 49%；四个预设 47–53%；爬山搜索（每次随机改一处，40 步）找到的最强设计在新种子上 55%。
- **得分占比会压缩差距，胜率不会。** 同样一批设计，占比只在 47–56% 之间，胜率却从 25% 到 94%。原因：双方的体量大部分来自同一片食物，占比天然靠近 50%。天梯应按胜负结算，衡量梯度也该看胜率。
- **搜索找到一个漏洞：农田刷屏。** 把起手设计的孵化规则换成一条"储量 ≥ 30 → 建农田"，胜率从 38% 升到 94%，占比 56%；把农田限制为 3 块，胜率降到 69%。原因是设施没有代价：建设施时储量 1:1 变成设施体量，仍然计入得分；设施不耗能，不衰减；每块农田每 300 刻还长 9 点食物。投资既没有损失也没有风险，收益却持续，所以"只建农田、不孵化"压倒一切。
- 其他发现：搜索出来的强设计里有不少永远不会触发的死规则，说明很多规则对结果几乎没有影响；从起手设计出发的搜索去掉了"回巢"，因为成员体量本来就计分。
- 结论：梯度不是太小，而是被两件事遮住了：占比指标压缩了差距；唯一的大梯度来自一个漏洞。下一步先修设施经济（待讨论方案），再用胜率重测梯度。

**设施耗能（2026-11-08，已采用）**：设施和成员一样耗能，按静止成员计算（在自己领地里减半），体量低于 4 就倒塌。这样世界规则少了一个例外：凡是存在的东西都会慢慢变小。新种子 8000+，各 16 局：
- 农田刷屏胜率 94% → 81%，占比 56% → 52%；起手设计 38% → 56%（预设里的农夫、象群也在交租，所以变弱了）；起手 + 3 块农田 69%。
- 只部分修好：每块农田在领地里每刻只交约 0.009 的租，却产出约 0.03 的食物。
- 探针（没有写进代码）：让农田把野外的食物点搬到自己家，而不是凭空新增食物点。这样全图食物总量守恒，但农田刷屏仍有 88% 胜率。对照：刷墙 6%，完全不孵化也不建设 38%。所以优势不在于多出来的食物，而在于把食物产地搬到自家门口：路途短，在自己领地里耗能减半，对手的食物还变少了。
- 占比只高 2–4 个点，但每局都赢，所以胜率被放大到 80–90%。问题的本质是农田投资没有反制手段：没有成员规则专门去吃敌方设施，而农田只在家门口，狼群的袭巢路线碰不到它。
- 预设两两对决（4 个种子）：狼群占比仍是 55–59%。

**反制：拆敌方设施（2026-11-08，已采用）**：新增成员条件"看到可拆的敌方设施"（视野内有体型够吃的敌方设施；农田需体量约 26 以上）和动作"拆敌方设施"（全速冲过去，碰到就吃掉）。世界规则不变，只是让"设施能被吃掉"这条规则有了主动的打法。预设族群没有改。
- 动作确实会触发，但要看有没有路过：狼群 + 拆设施对农田刷屏，3 个种子里有 2 局把对方农田拆光（终局 207:43、239:48），另一局根本没看到农田。
- 农田刷屏对狼群（12 个种子）：不拆 8/12、占比 56%；加拆设施 8/12、61%。
- 两两对决（8 个种子，胜局数）：狼群 + 拆设施几乎全胜（赢刷屏 7/8、起手 6/8、农夫 7/8、猎手 6/8）；刷屏胜过除它以外的所有设计（起手 6/8、农夫 7/8、猎手 5/8）。"猎手"（起手 + 拆设施 + 默认袭巢）对预设只赢 13%，对刷屏赢 67%。
- 结论：反制存在而且有效，但没有形成剪刀石头布，而是一条强弱链：狼群类 > 农田刷屏 > 均衡打法。眼下的头号问题回到老问题：狼群太强，没有克星。

**两层优雅**：规则优雅，好的 bot 也优雅。就像囚徒困境锦标赛里只有两行的"以牙还牙"击败了复杂的对手，最好的 bot 应该简短而巧妙。

**核心玩法要满足的四点**：
- 没有通吃的策略，任何打法都有克星，强弱随对手群体变化。
- 不能被暴力计算通吃，比的是理解，不是算力。
- 局面能用人话描述，非程序员才写得出规则。
- 观众一眼看懂。

**bot 就是测量玩法的仪器**：经典游戏要经过漫长岁月才被筛选出来；我们可以用几千局自动对局，在几天内量化一套玩法好不好。

## 核心玩法候选一：圆台推挤（待验证）

以下"规则""构成""变化从哪里来"三节都属于这个候选。

### 规则

> 1. 每个角色是一个圆，按自己的性格在圆台上移动。
> 2. 相撞时按质量推开：重的推轻的。
> 3. 掉出圆台就出局，最后留下的角色获胜。

圆台随时间缓慢缩小，保证对局会结束。

### bot 由什么构成

| 设计 | 内容 | 为什么够用 |
|---|---|---|
| **体型** | 一个数，大或小 | 物理自动给出取舍：大的重、难推但慢；小的轻、灵活但一撞就飞。不需要代价表 |
| **性格** | 一组"条件 → 动作"规则，从上到下匹配 | 什么时候进、什么时候退、找谁打、躲着谁，全部在这里 |

所有角色共有同一个动作集：**移动**（选方向）和**冲刺**（短时加速，有冷却）。
冲刺的时机就是最核心的博弈：冲早了扑空，自己可能冲出圆台。

### 性格分层：门槛低，天花板高

| 层 | 玩家能做什么 | 带来什么 |
|---|---|---|
| L1 性格词 | 选"胆小、记仇、贪婪、爱偷袭、渔翁"等，自动展开成规则 | 一分钟上手 |
| L2 优先规则 | 条件 → 动作，从上到下匹配，可改 L1 展开的规则 | 基本风格 |
| L3 偏好打分 | 候选动作按特征加权（离边缘远 +3、对手正在打架 +2） | 同一风格里的细腻差异 |
| L4 记忆与模式 | 变量和状态切换："被撞过就报复""领先就转保守" | 有性格、有阶段感 |
| L5 读对手 | 读取对手的历史行为与倾向，针对性反制 | 最深的一层，没有尽头 |

**复杂度预算**：每块积木有成本，总量有上限。读对手很贵，简单规则便宜。玩家必须取舍，钱花在"想得细"还是"读得准"；预算也逼出简短优雅的好设计。

### 变化从哪里来

三条规则、两个设计维度，预期产生的矛盾（推演，待原型验证）：

| 矛盾 | 一边 | 另一边 |
|---|---|---|
| 大与小 | 大的稳 | 小的快，能绕到背后 |
| 进与等 | 主动冲刺能把人撞出去 | 扑空就把自己送到边缘 |
| 中与边 | 待在中心最安全 | 所有人都想去中心，那里最挤 |
| 打与看 | 先出手争取主动 | 等别人两败俱伤再收割 |

多人同场时，"找谁打"本身就是策略：落井下石、联手打最强者、躲着渔翁。

## 公平

- 同样的规则、同样的动作集，只有体型和性格不同。
- 引擎确定性：同一组角色和种子，结果完全一致。
- 出生位置对称并轮换，每组对手打多局，排名看大量对局的统计结果。
- 对局中不调用大模型。

## 观战

- 实时动画，角色头上显示当前触发的规则（"等待时机""冲刺！""逃离边缘"）。
- 一眼能看懂：谁在中心，谁在边缘，谁刚被撞飞。
- 可以跟随单个 bot，看它的视角。
- **回放即调试器**：点任意时刻，看 bot 当时看到了什么、命中了哪条规则。玩家能把失败的瞬间直接存成测试场景，改完 bot 后重放验证。
- **高光自动剪辑**：以小博大、边缘翻盘、渔翁得利。
- **从回放里猜对手**：对手的规则不公开，但可以从它的行为推测，天梯因此有学习和反制。
- **观战下注**：用虚拟积分押胜负，不涉及真钱。

## 验证

规则是否真的"简单而深"，用自动锦标赛判断，不凭感觉：

- 克制关系成环，没有通吃的体型或性格。
- 排名前列的角色风格多样。
- 设计得更好的角色稳定地更强。
- 出生位置没有优势，对局长度适中，僵局少。

**可塑性测量**：
- 在积木空间里自动搜索、演化一大批 bot，看强 bot 是否收敛到同一种原型。收敛说明可塑性低。
- 按行为特征（进攻性、贴边时间、冲刺时机等）给 bot 聚类，看前列分成几种风格，风格之间有没有克制环。

如果不达标，先调整参数（圆台大小、缩圈速度、冲刺冷却），不轻易加规则。

## 路线

| 阶段 | 内容 | 完成标准 |
|---|---|---|
| **M0** | 三条规则 + 6 个预置角色 + 实时观战 + 自动锦标赛 | 结果可复现；没有通吃的角色 |
| **M1** | 设计路径：调体型、写性格规则，一键测试 | 新玩家 5 分钟内造出 bot 并打完一局 |
| **M2** | 养成路径：表扬/纠正、陪练、示范，训练次数有上限 | 养成的 bot 能明显变强，且看得出它学会了什么 |
| **M3** | 天梯：提交 bot，自动匹配，排名 | 排名稳定 |

## 扩展层：在核心之上加机制和玩法

无论最终选定哪个核心玩法，核心一旦确定就保持不变，天梯主赛制只用核心。下面的候选以圆台推挤为例。有趣的机制做成**可开关的模块**，挂在核心之上。

**模块的规矩**
1. 每个模块只用一句话说清楚。
2. 不给角色增加新的设计项：同一个角色可以直接参加任何模式（必要时性格规则里多几个可选的条件词）。
3. 一次只开少数几个模块，组合成一个模式或一个赛季。
4. 上线前同样过一遍自动锦标赛，确认没有让某种角色通吃。

**场地机制（候选）**

| 模块 | 一句话规则 | 带来的新玩法 |
|---|---|---|
| 冰面 | 部分区域摩擦很小 | 冲刺后停不下来，诱敌上冰 |
| 柱子 | 场上有不可推动的障碍 | 卡位、借柱子反弹、躲在柱后 |
| 弹板 | 撞到边缘弹板会被弹回 | 边缘不再必死，敢于贴边 |
| 洞 | 场内有会开合的洞 | 第二种"出局"，抓时机 |
| 移动圆台 | 圆台中心会缓慢漂移 | 安全区一直在变 |
| 风 | 周期性朝一个方向吹 | 顺风冲刺更远，逆风更难 |
| 视野 | bot 只能看到身边一定范围 | 侦察、记忆、伏击；迷雾来自身体，而不是硬加的规则 |
| 夜晚 | 周期性视野减半 | 节奏变化 |

**模式（候选）**

| 模式 | 一句话规则 | 考验 |
|---|---|---|
| 团队赛 | 2v2 / 3v3，最后有队友留下的一方赢 | 配合，保护队友 |
| 占点 | 站在中心光圈里累计时间，时间多者赢 | 抢与守 |
| 能量豆 | 场上刷豆，吃到的角色变大 | 贪与险；连接生命世界的觅食 |
| 王者 | 一个角色体型最大，其余联手推它 | 以多打一 |
| 挑战关卡 | 用不超过 N 条规则通过指定场景 | 教学和解谜 |
| 组队搭档 | 两个玩家的 bot 组队 | 单个强不等于配合好 |
| 争食 | 打开能量规则：活着耗能、大吃小、吃了变大 | 觅食、掠夺；生命世界的入口 |

**身体零件（候选）**：冲刺之外的能力，如硬壳（更稳但更重）、尖刺（推力更强但更耗能）、钩爪（拉人但发射时僵直）。每件都带代价和弱点。适合作为赛季变异器或特定模式，不进核心。

**赛季变异器**：每个赛季给天梯额外开一个模块，迫使大家重新调整角色，保持新鲜感；赛季结束后核心天梯恢复原样。

## 以后再说

- **生命世界**：同一套物理下，bot 能觅食、繁衍成谱系，作为世界观；也可以作为养成的场所。
- **AI 助手的实现**：等规则词表在 M1 定型后接入。

## 附录：创意库

讨论过的所有创意，按去向归档，方便以后翻找。

**已进入核心**
- 规则列表作为 bot 的"源码"：透明、确定、可复现。
- 同时行动、对称开局、换位多局：公平来自结构。
- 意图气泡：观众看懂，玩家调试。
- 角色 = 身体 + 性格；bot 是画面中的实体。
- 一种身体参数（体型），代价由物理自动给出。

**进入扩展层**（见上文）
场地机制、模式、视野迷雾、身体零件、赛季变异器、挑战关卡、组队搭档、观战下注。

**其他核心玩法候选**（与圆台推挤并列，可以继续增补）

| 方案 | 规则 | 优点 | 顾虑 |
|---|---|---|---|
| 圈地 | 离开领地拖出尾迹，回家时圈地；尾迹被踩就出局 | 贪与怕直观，观赏性强 | 已有同类玩法先例 |
| 光迹 | 走过留墙，撞墙出局，最后存活者赢 | 规则只有两句 | 策略容易收敛到空间启发 |
| 疆 | 同时走，近者得地，以多吃少 | 散与聚的张力 | 需要每方多个棋子 |
| 同步围棋 | 围棋规则 + 同时落子 + 撞点成废墟 | 深度最大 | 概念对非程序员偏难，画面静态 |
| 能量生态 | 活着耗能、大吃小、阳光生草、分裂繁殖 | 捕食链天然形成克制环 | 规则偏多，适合生命世界 |

**暂时放弃**
| 创意 | 原因 |
|---|---|
| 性格只用滑杆 | 深度太浅，天梯会收敛到一组最优参数 |
| 4 人混战作为唯一天梯 | 席位偏差、方差大、第三名能决定谁拿第一；需要大量对局平滑 |
| 资源 + 控制 + 战斗加权计分 | 各系统相加，总有一个沦为装饰（RMTC 的教训） |
| 线上运行玩家任意代码 | 安全成本高，且与非程序员定位无关 |
| 对局中实时调用大模型 | 延迟、成本、不可复现，破坏公平 |
